# 📊 Simulador de Investimentos 

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio da DIO, com o objetivo de aplicar conhecimentos de Excel na construção de uma ferramenta para simulação de investimentos em Fundos Imobiliários (FIIs).

A planilha foi desenvolvida para permitir a análise de diferentes cenários de investimento, considerando informações como patrimônio, aportes e geração de dividendos.

## 🎯 Objetivo

O objetivo do projeto é criar uma ferramenta prática que permita simular investimentos em FIIs e analisar diferentes possibilidades de crescimento do patrimônio ao longo do tempo.

Através da ferramenta, é possível alterar diferentes variáveis e observar como elas influenciam os resultados da simulação.

## 📋 Estrutura do projeto

O desenvolvimento da planilha envolveu os seguintes conceitos:

### Introdução

Apresentação da proposta do simulador e dos objetivos da ferramenta.

### Perguntas de negócio

Definição das informações necessárias para realizar as simulações e apoiar a análise dos resultados.

### Pré-requisitos

Identificação dos dados necessários para realizar os cálculos e utilizar corretamente a ferramenta.

### Base da tabela

Organização dos dados utilizados como base para os cálculos e simulações.

### Simulador de patrimônio

Construção de uma ferramenta para visualizar a evolução do patrimônio de acordo com os valores definidos na simulação.

### Simulador de cenários

Criação de diferentes cenários para analisar como alterações nas variáveis podem impactar os resultados.

### Variáveis globais

Organização das principais variáveis utilizadas nos cálculos, facilitando a manutenção e utilização da planilha.

### Nomeando intervalos

Utilização de nomes para intervalos de células, tornando as fórmulas mais organizadas e compreensíveis.

### Uniformidade visual

Aplicação de uma padronização visual para facilitar a leitura e utilização da ferramenta.

### Tipos de fundo

Consideração das diferentes características dos Fundos de Investimento Imobiliário dentro da proposta de simulação.

## 🛠️ Tecnologias e ferramentas

- Microsoft Excel
- Fórmulas e funções do Excel
- Tabelas
- Simulação de cenários
- Cálculos financeiros
- Formatação e organização de planilhas

## 📈 Resultados

A ferramenta permite realizar simulações a partir dos dados informados pelo usuário, possibilitando observar diferentes cenários de evolução do patrimônio e estimativas relacionadas aos investimentos em FIIs.

## 📂 Arquivo

- `Desafio_Dio.xlsx` — arquivo Excel contendo a ferramenta de simulação de investimentos em Fundos Imobiliários desenvolvida durante o desafio.

## 📚 Aprendizados

Durante o desenvolvimento do projeto, foram praticados conceitos relacionados à criação e organização de planilhas, utilização de fórmulas, definição de variáveis, nomeação de intervalos, criação de cenários e organização visual de ferramentas desenvolvidas no Excel.

O projeto também possibilitou aplicar o Excel em uma situação prática de análise e simulação de investimentos.

## ⚠️ Observação

Este projeto possui finalidade educacional. Os resultados apresentados pela planilha dependem dos dados e premissas utilizados na simulação e não representam garantia de rentabilidade futura.
